# Matrix Brand Palette

Source: `paxlabs-inc/matrix-brand-kit/tokens/colors.css`

## Aesthetic
Warm-charcoal: warm near-black base, warm-neutral (stone) scale, cream text, sage as the single accent. Every neutral is nudged toward yellow/red, not blue.

## Key Colors

| Token | Hex | Usage |
|-------|-----|-------|
| Background | `#161615` | Page canvas, warm charcoal |
| Foreground | `#e3d9d4` | Primary text, warm cream |
| Card | `#1b1b19` | Cards, elevated surfaces |
| Sage accent | `#99bd9c` | THE accent — ring, highlights, pills |
| Sage soft | `#99bd9c24` | Subtle accent backgrounds |
| Sage softer | `#99bd9c14` | Very subtle accent |
| Muted text | `#96918e` | Secondary text |
| Border | `#2a2a27` | Medium borders |
| Amber warning | `#fe9a00` | Notification / upgrade tint |
| Brand purple | `#ab68ff` | Out-of-palette brand token |
